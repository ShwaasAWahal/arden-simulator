# Arden Simulator

An educational simulator for the course *Automata Theory and Computability* that
converts a finite automaton (FA) into an equivalent regular expression (RE) using
**Arden's theorem**. It builds one left-linear equation per state, solves the
system by substitution and Arden's rule while recording every step, simplifies
the result, verifies it against the automaton, and lets you explore or export
the full derivation.
